# Peculiar Systems

Small software studio. We build sharp, narrow tools for problems big companies ignore — one job, one buyer, one outcome.

**InvoiceIn** — any European e-invoice a business *receives* (XRechnung, ZUGFeRD/Factur-X, UBL, CII, Peppol BIS 3, FatturaPA, KSeF FA(3)) → one canonical EN 16931 JSON, a validation report with plain-language fix hints in EN/DE/PL/IT/FR, PDF, CSV and DATEV. Nothing stored, not an access point.
